# 🚀 ФИНАЛЬНАЯ ИНСТРУКЦИЯ по сборке APK

## ✅ Всё готово к сборке!

Проект **Lumina LifeOS** полностью настроен для сборки в Android APK.
Веб-приложение React перенесено в Android с помощью **Capacitor**.

---

## 📋 Что нужно сделать

### Шаг 1: Установите Android Studio

**Вариант А: Через winget (автоматически)**
```bash
winget install Google.AndroidStudio
```

**Вариант Б: Вручную**
1. Скачайте с официального сайта: https://developer.android.com/studio
2. Запустите установщик
3. Следуйте инструкциям мастера установки

---

### Шаг 2: Откройте проект в Android Studio

**Способ 1: Через команду (рекомендуется)**
```bash
npm run cap:open
```

**Способ 2: Через скрипт**
```bash
.\build-apk.ps1
```
Или:
```bash
.\check-android-studio.bat
```

**Способ 3: Вручную**
1. Запустите Android Studio
2. Выберите "Open an Existing Project"
3. Укажите папку: `C:\Users\Yan\Desktop\apk LUMINA\LIFE OS\android`

---

### Шаг 3: Дождитесь синхронизации

После открытия проекта:
- Android Studio загрузит зависимости Gradle
- Проиндексирует файлы
- Может предложить обновить Gradle или Android Gradle Plugin

**Это займёт 2-5 минут при первом запуске.**

---

### Шаг 4: Соберите APK

В Android Studio:
1. Меню: **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**
2. Дождитесь завершения сборки (1-2 минуты)
3. Внизу появится уведомление "APK(s) generated successfully"

---

### Шаг 5: Найдите APK файл

APK находится в папке:
```
C:\Users\Yan\Desktop\apk LUMINA\LIFE OS\android\app\build\outputs\apk\debug\app-debug.apk
```

Или откройте через меню:
**Build** → **Open APK Location**

---

## 📱 Установка на телефон

### Через USB кабель:
1. Включите **Отладку по USB** на телефоне:
   - Настройки → О телефоне → 7 раз нажмите "Номер сборки"
   - Настройки → Для разработчиков → Отладка по USB
2. Подключите телефон к компьютеру
3. Установите APK:
   ```bash
   adb install android/app/build/outputs/apk/debug/app-debug.apk
   ```

### Прямая установка:
1. Скопируйте APK файл на телефон
2. Откройте через файловый менеджер
3. Разрешите установку из неизвестных источников
4. Нажмите "Установить"

## 🔧 Обновление приложения

После изменений в коде:

```bash
# 1. Пересоберите веб-приложение
npm run build

# 2. Синхронизируйте с Android
npx cap sync android

# 3. Откройте в Android Studio
npm run cap:open

# 4. Соберите APK заново
```

Или используйте команду:
```bash
npm run android:build
```

## ❓ Решение проблем

### "SDK location not found"
Android Studio автоматически настроит SDK при первом запуске.
Если ошибка остаётся:
1. File → Project Structure → SDK Location
2. Укажите путь к Android SDK

### "Gradle sync failed"
1. File → Invalidate Caches → Restart
2. Попробуйте снова

### "Build failed - mergeDebugResources"
1. Очистите проект: Build → Clean Project
2. Пересоберите: Build → Rebuild Project

### "Java not found"
Java JDK 17 уже установлен:
`C:\Program Files\Microsoft\jdk-17.0.18.8-hotspot`
