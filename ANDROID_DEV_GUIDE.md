# Как быстро обновлять приложение в Android Studio

Android Studio не видит ваши изменения в `src/`, пока вы не «соберете» их и не «синхронизируете». Вот 3 способа сделать это без мучений.

---

## Способ 1: Одна команда (Рекомендуется)
После того как я (AI) внес правки, просто запустите файл:
👉 **`SYNC_ANDROID.bat`** в папке `LIFE OS`.

Он сам:
1. Скомпилирует TypeScript и React.
2. Скопирует файлы в папку `android/`.
3. Обновит все зависимости.

После этого в Android Studio просто нажмите кнопку **Run** (зеленый треугольник).

---

## Способ 2: Live Reload (Мгновенные правки)
Это лучший способ для разработки. Вы правите код — телефон обновляется сам.

1. Запустите сервер в терминале:
   ```bash
   npm run dev -- --host
   ```
2. Посмотрите ваш IP (например, `192.168.1.5`).
3. В файле `capacitor.config.ts` временно добавьте ваш IP:
   ```typescript
   server: {
     url: 'http://192.168.1.5:5173', // Ваш IP
     cleartext: true
   }
   ```
4. Выполните `npx cap copy android`.
5. Запустите приложение из Android Studio.
6. **Теперь любые изменения кода будут появляться на телефоне сразу!**

---

## Способ 3: Команды в терминале
Если вы любите консоль, используйте эти сокращения:

- `npm run android:fast` — быстрая сборка и копирование (только код).
- `npm run android:build` — полная сборка (если добавили новые плагины/библиотеки).

---

### Почему раньше были старые версии?
Потому что Android Studio запускает код из папки `android/app/src/main/assets/public`. Когда мы меняем файлы в `src/`, папка `assets/public` остается старой, пока не будет вызвана команда `cap sync` или `cap copy`.
