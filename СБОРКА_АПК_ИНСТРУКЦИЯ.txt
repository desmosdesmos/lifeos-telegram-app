═══════════════════════════════════════════════════════════════
  СПОСОБ 1: Через Android Studio (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════════

1. Android Studio уже открыта с проектом

2. Дождитесь завершения синхронизации Gradle (индикатор внизу)

3. Меню: Build → Build Bundle(s) / APK(s) → Build APK(s)

4. Готово! APK будет в:
   android\app\build\outputs\apk\debug\app-debug.apk

═══════════════════════════════════════════════════════════════
  СПОСОБ 2: Через скрипт
═══════════════════════════════════════════════════════════════

1. Откройте проводник
2. Перейдите в: C:\Users\Yan\Desktop\apk LUMINA\LIFE OS
3. Дважды кликните на: СОБРАТЬ_АПК.bat

═══════════════════════════════════════════════════════════════
  СПОСОБ 3: Вручную в командной строке
═══════════════════════════════════════════════════════════════

1. Откройте Terminal в Android Studio (View → Tool Windows → Terminal)

2. Выполните команду:
   cd android
   gradlew assembleDebug

3. APK появится в:
   android\app\build\outputs\apk\debug\app-debug.apk

  УСТАНОВКА НА УСТРОЙСТВО
═══════════════════════════════════════════════════════════════

Через ADB:
  adb install android\app\build\outputs\apk\debug\app-debug.apk

Или скопируйте APK на телефон и установите как обычный файл.
