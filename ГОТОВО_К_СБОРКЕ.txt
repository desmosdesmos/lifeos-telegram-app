  СБОРКА ЧЕРЕЗ ANDROID STUDIO (1 минута)
═══════════════════════════════════════════════════════════════

Android Studio уже открыта с проектом.

1. Дождитесь окончания "Indexing..." и "Gradle Sync" (внизу справа)

2. В меню выберите:
   Build → Build Bundle(s) / APK(s) → Build APK(s)

3. Готово! APK появится в:
   android\app\build\outputs\apk\debug\app-debug.apk

4. Нажмите "locate" во всплывающем уведомлении, чтобы открыть папку

═══════════════════════════════════════════════════════════════
  СБОРКА ЧЕРЕЗ TERMINAL В ANDROID STUDIO
═══════════════════════════════════════════════════════════════

1. View → Tool Windows → Terminal (или Alt+F12)

2. Выполните:
   gradlew assembleDebug

3. APK будет в:
   app\build\outputs\apk\debug\app-debug.apk

  УСТАНОВКА НА ТЕЛЕФОН
═══════════════════════════════════════════════════════════════

Способ 1: Через USB
  1. Включите "Отладку по USB" на телефоне
  2. Подключите к ПК
  3. adb install app-debug.apk

Способ 2: Прямая установка
  1. Скопируйте app-debug.apk на телефон
  2. Откройте через файловый менеджер
  3. Разрешите установку из неизвестных источников
