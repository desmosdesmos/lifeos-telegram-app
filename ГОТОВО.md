## 🎯 Как собрать APK

### Вариант 1: Через Android Studio (РЕКОМЕНДУЕТСЯ)

**Шаг 1. Установите Android Studio**

Скачайте с официального сайта:
https://developer.android.com/studio

Или через winget (уже установлено в фоне):
```bash
winget install Google.AndroidStudio
```

**Шаг 2. Откройте проект**
```bash
npm run cap:open
```

Или дважды кликните на файл:
```
check-android-studio.bat
```

**Шаг 3. Дождитесь синхронизации Gradle**

**Шаг 4. Соберите APK**
- Меню: `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`

**Готово!** APK файл находится в:
```
android\app\build\outputs\apk\debug\app-debug.apk
```

---

### Вариант 2: Через командную строку (требуется Java и Android SDK)

```bash
# 1. Сборка веб-приложения
npm run build

# 2. Синхронизация с Capacitor
npx cap sync android

# 3. Сборка APK через Gradle
cd android
gradlew.bat assembleDebug
```

## ❓ Частые вопросы

### Q: Где взять APK файл?
A: После сборки в Android Studio APK находится в:
`android\app\build\outputs\apk\debug\app-debug.apk`

### Q: Как обновить приложение после изменений в коде?
A: Выполните:
```bash
npm run android:build
```
Затем пересоберите APK в Android Studio.

### Q: Можно ли собрать без Android Studio?
A: Да, если установлены Java JDK и Android SDK:
```bash
cd android
gradlew.bat assembleDebug
```

### Q: Как сделать release версию?
A: В Android Studio:
`Build` → `Generate Signed Bundle / APK` → Выберите `APK` → Создайте ключ подписи
