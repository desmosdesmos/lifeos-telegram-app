## 🚀 ИНСТРУКЦИЯ ПО СБОРКЕ

### Шаг 1: Установите Android Studio

**Скачайте с официального сайта:**
https://developer.android.com/studio

**Или через winget:**
```bash
winget install Google.AndroidStudio
```

### Шаг 2: Откройте проект в Android Studio

**Команда:**
```bash
npm run cap:open
```

**Или вручную:**
1. Запустите Android Studio
2. File → Open
3. Выберите папку: `C:\Users\Yan\Desktop\apk LUMINA\LIFE OS\android`

### Шаг 3: Дождитесь синхронизации

Android Studio:
- Загрузит зависимости Gradle
- Настроит Android SDK
- Проиндексирует файлы

**Это займёт 3-5 минут при первом запуске.**

### Шаг 4: Соберите APK

В Android Studio:
1. **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**
2. Дождитесь завершения (1-2 минуты)

### Шаг 5: Найдите APK

APK находится в папке:
```
android\app\build\outputs\apk\debug\app-debug.apk
```

## 📱 Установка на телефон

### Через USB:
1. Включите **Отладку по USB** на телефоне
2. Подключите к компьютеру
3. Установите:
   ```bash
   adb install android/app/build/outputs/apk/debug/app-debug.apk
   ```

### Прямая установка:
- Скопируйте APK на телефон
- Откройте через файловый менеджер
- Установите

## ❓ Решение проблем

### "SDK location not found"
Android Studio автоматически настроит SDK при первом запуске.

### "Gradle sync failed"
File → Invalidate Caches → Restart

### "Build failed"
Build → Clean Project → Rebuild Project
